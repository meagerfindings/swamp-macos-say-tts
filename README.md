# swamp-macos-say-tts

[swamp](https://swamp.club) extension `@mgreten/macos-say-tts` — speak text
aloud on macOS using the built-in `say` voice synthesizer.

📖 **Extension documentation:** [extensions/models/README.md](extensions/models/README.md)

📦 **Install:** `swamp extension pull @mgreten/macos-say-tts`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable extension lives under [extensions/models/](extensions/models/).

## Requirements

macOS only — relies on the native `say` and `afplay` binaries.
